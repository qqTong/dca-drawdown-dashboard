# 我给自己的定投上了几条规矩，免得一跌就想抄底，一涨就想辞职

最近我重新整理了一遍自己的长期定投计划。

原因也很朴素：行情平静的时候，人人都是长期主义者；市场一跌，手就会自动打开账户，脑子里只剩一句话：

> 这么便宜，不多买一点是不是对不起自己？

然后再跌 20%，才发现自己真正对不起的是现金余额。

所以我决定不再靠当天的心情投资，而是提前把金额、加仓和止盈规则写下来。市场负责涨跌，我负责别乱来。

我的投资标的是标普 500、纳斯达克 100 和 BTC，计划至少坚持 10 年。下面是目前采用的版本。

## 一、每周买多少：先活下来，再谈复利

我原本每天投入大约 340 元：

- 纳指 160 元
- 标普 40 元
- BTC 约 140 元

乍一看雨露均沾，仔细一算却发现，BTC 占新增资金约 41%。如果 QDII 只在交易日扣款，而 BTC 每天都买，它的实际占比甚至可能超过 50%。

这就不是资产配置了，更像给自己的睡眠质量做压力测试。

所以我把每天定投改成了每周定投，每周预算约 2,380 元：

| 用途 | 每周金额 |
|---|---:|
| 标普 500 或全球宽基 | 1,050 元 |
| 纳斯达克 100 | 700 元 |
| BTC | 210 元 |
| 加仓储备金 | 420 元 |

长期目标仓位是：

- 标普或全球宽基：45%
- 纳指：30%
- BTC：10%
- 现金、货币基金或短债：15%

这里最容易被忽略的是最后一项。

很多人觉得现金不产生收益，是在“拖累组合”。但熊市来了以后，现金会突然从拖油瓶变成全场最有安全感的人。

加仓储备金不是闲钱，它买的是未来下跌时的行动能力。

另外，我给 BTC 设置了 15%的仓位上限。超过以后停止定投，不管群里有多少人喊“这次不一样”。

## 二、什么时候加仓：看历史回撤，不看我的情绪

我不再根据“今天跌得挺多”决定加仓，因为单日跌 3%可能只是开胃菜，也可能第二天就涨回去。

我的加仓依据只有一个：

```text
回撤率 = 1 - 最新完整收盘价 ÷ 历史最高收盘价
```

注意，是历史最高**收盘价**，不是盘中某一分钟冲上去拍完照就下来的价格。

### 标普 500

| 距历史高点回撤 | 本周投入 |
|---:|---:|
| 不足 10% | 1 倍 |
| 10%–20% | 1.25 倍 |
| 20%–30% | 1.5 倍 |
| 30%–40% | 2 倍 |
| 40%以上 | 2.5 倍 |

### 纳斯达克 100

| 距历史高点回撤 | 本周投入 |
|---:|---:|
| 不足 10% | 1 倍 |
| 10%–20% | 1.25 倍 |
| 20%–30% | 1.5 倍 |
| 30%–40% | 2 倍 |
| 40%–50% | 2.5 倍 |
| 50%以上 | 3 倍 |

### BTC

BTC 平时波动就比较有个人风格，所以它的门槛更深：

| 距历史高点回撤 | 本周投入 |
|---:|---:|
| 不足 20% | 1 倍 |
| 20%–35% | 1.25 倍 |
| 35%–50% | 1.5 倍 |
| 50%–65% | 2 倍 |
| 65%以上 | 2.5 倍 |

但有一个前提：BTC 在整个组合中的仓位必须低于 15%。

价格跌得再多，也不能成为无视仓位的理由。否则所谓“越跌越买”，最后很可能变成“只剩它可以买”。

### 举个例子

假设某周：

- 标普回撤 22%，投入 `1,050 × 1.5 = 1,575 元`
- 纳指回撤 32%，投入 `700 × 2 = 1,400 元`
- BTC 回撤 40%，投入 `210 × 1.5 = 315 元`

额外的钱从加仓储备金里出。

如果储备金不够，优先级是：

1. 标普
2. 纳指
3. BTC

不是谁跌得最惨就先救谁。投资组合不是急诊室，跌幅最大也不代表最值得投入。

为了避免熊市刚开场就打光子弹，我还给自己加了几条限制：

- 单周总投入最多为平时的 2.5 倍
- 不借钱、不融资、不刷信用卡抄底
- QDII 限购后，没买进去的钱留在货币基金，不顺手全塞给 BTC
- 某个回撤档位持续数周，就按该档位每周投入，不一次性梭哈

梭哈最大的优点，是下单时很有气势；最大的缺点，是之后只能用气势扛跌。

## 三、赚了以后怎么办：不清仓，做再平衡

宽基指数我不采用“涨 20%就止盈”的办法。

因为长期投资最尴尬的事情之一，就是好不容易买到了长期上涨的资产，却因为赚了一点就把它卖了，然后眼看它继续上涨，再找一个更高的位置买回来。

所以我的止盈不是猜顶部，而是控制仓位。

每半年检查一次：

| 资产 | 目标仓位 | 处理规则 |
|---|---:|---|
| 标普/全球宽基 | 45% | 超过 55%时调回 45%–50% |
| 纳指 | 30% | 超过 40%时调回 30%–35% |
| BTC | 10% | 达到 15%停止买入 |
| BTC | 10% | 达到 18%卖回 15% |
| BTC | 10% | 达到 20%卖回 10%–12% |

处理顺序也很重要：

1. 先暂停超配资产的定投
2. 把新钱投入低配资产
3. 仍然严重超配，再卖出一部分

这叫“不卖出式止盈”。能用新资金解决的问题，先别急着制造交易费和“卖完继续涨”的心理创伤。

BTC 止盈出来的钱，我会放回标普和现金储备，不会因为它刚涨完就立刻追进去。

如果未来有明确的用钱时间，比如买房、教育或退休，也不能永远保持同样的风险：

- 距离用钱 5 年：开始逐年增加低风险资产
- 距离用钱 3 年：逐步锁定未来三年确定要用的钱
- 距离用钱 1 年：这笔钱不再放在股票和 BTC 里

市场可以等十年，但房东、学校和退休生活未必愿意配合市场周期。

## 四、场内还是场外：没有完美答案，只有不同的麻烦

### 场外 QDII

场外更适合我这种单笔金额不大、希望自动扣款，又不想上班时偷偷切到交易软件的人。

优点是：

- 可以小额自动定投
- 没有场内供需造成的高溢价
- 不用盯盘

缺点是按照未知净值成交。

比如周一晚纳指回撤达到 20%，我周二 15:00 前申购，最终买到的是周二对应的基金净值。周二晚美股可能反弹，也可能继续跌，所以不可能精准买在看到信号的那个位置。

我的处理办法是：大额加仓拆成两次。

- 第一次投入计划金额的 60%–70%
- 隔两天重新看回撤，再决定是否投入剩余部分

毕竟我们是在做长期定投，不是在参加“谁最接近最低点”竞猜。

### 场内 QDII ETF

场内适合佣金低、单笔金额较大，并且愿意检查溢价的人。

我一般在周三上午 10:00–11:00，或者下午 13:30–14:30 操作，避开刚开盘和临近收盘。

下单前先看溢价：

| 场内溢价 | 我的操作 |
|---:|---|
| 低于 0.5% | 正常买 |
| 0.5%–1% | 小额买 |
| 1%–2% | 等一等 |
| 超过 2% | 不买 |

指数大跌，不代表场内 ETF 就便宜。

QDII 额度紧张时，大家可能把 ETF 抢出很高的溢价。此时你以为自己在抄底，实际上是在给别人支付情绪加价。

所以我的最终选择是：

> 场外负责基础定投，场内负责低溢价时的大回撤加仓。

场内贵了就等，场外限购就把钱留在货币基金。没有规定今天计划投资的钱，今天必须想办法花完。

## 最后

这套策略不能保证收益最高，也不可能让我每次都买在最低点。

它真正想解决的是三个问题：

1. 上涨时别因为兴奋无限提高风险
2. 下跌时别因为恐慌停止投入
3. 真正的大跌来临时，手里还有钱

投资十年，决定结果的可能不是哪一次抄底特别漂亮，而是在无聊、恐慌和亢奋里，是否一直执行同一套规则。

市场每天都有新故事，但我的转账密码不应该每天都有新想法。

---

以上只是我的个人定投记录，不构成投资建议。投资有风险，尤其是 BTC，它有时不只让资产波动，也会顺便测试心率。
