# 回撤定投仪表盘

每天读取纳斯达克100、标普500和BTC的前一完整日线收盘价，计算其相对历史最高收盘价的回撤，并按预设档位给出当日定投金额。

完整执行方案见 [纳指、标普与 BTC 定投策略](docs/dca-investment-plan.md)。

适合社交平台发布的版本见 [我的长期定投规则：活人版](docs/dca-strategy-social-post.md)。

## 运行

需要 Node.js 18 或更高版本：

```powershell
npm start
```

然后打开 `http://127.0.0.1:4173`。服务默认监听 `0.0.0.0`，以兼容 Render 等云平台；本机仍通过上述地址访问。

服务启动时会立即更新数据，之后每天北京时间 `08:10` 自动刷新。页面右上角也可以手动刷新。

## 默认规则

- 纳斯达克100：回撤10%、20%、30%、40%、50%时逐档提高到1.25、1.5、2、2.5、3倍。
- 标普500：回撤10%、20%、30%、40%时逐档提高到1.25、1.5、2、2.5倍。
- BTC：回撤20%、35%、50%、65%时逐档提高到1.25、1.5、2、2.5倍。

基础金额可在页面修改，并保存在浏览器本地。BTC达到投资组合15%时，应忽略加仓建议并停止买入。

## 数据口径

- 美股指数使用纽约市场已经完成的日线。
- BTC使用UTC已经完成的日线，不使用当天尚未收盘的K线。
- 历史高点指历史最高日线收盘价，不是盘中最高价。
- 场外QDII按未知净值成交；页面建议用于确定投入预算，不代表可以按显示指数点位成交。

## 部署到 Render

1. 将项目推送到 GitHub、GitLab 或 Bitbucket。
2. 登录 Render，选择 **New > Blueprint**。
3. 连接代码仓库；Render 会读取根目录的 `render.yaml`。
4. 为 `ACCESS_USER` 和 `ACCESS_PASSWORD` 设置访问用户名与强密码。
5. 部署完成后，通过 Render 提供的 `https://...onrender.com` 地址访问。

免费实例连续15分钟没有请求时会休眠，下一次打开可能需要约一分钟唤醒。需要稳定即时访问时可升级为付费实例。

也可以在本机启用密码保护：

```powershell
$env:ACCESS_USER="your-name"
$env:ACCESS_PASSWORD="a-long-random-password"
npm start
```
